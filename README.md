-
*💎 ADAMANTITE EXPANSION*
-
Adamantite Expansion - контентный мод для Minecraft 1.12.2, расширяющий позднюю стадию игры за счёт добавления нового редкого и прочного металла - адамантита. Мод вводит полноценную ветку развития, включающую генерацию новой руды, переработку ресурсов, создание инструментов, оружия и брони.
-
_1. ⛰️ГЕНЕРАЦИЯ И ДОБЫЧА_
-
Адамантитовая руда генерируется на большой глубине в обычном мире (Overworld). 
Месторождения встречаются значительно реже алмазной руды, что делает поиск адамантита отдельной задачей для игрока.
Для добычи адамантитовой руды требуется алмазная кирка или инструмент более высокого уровня. 
При разрушении блока выпадает сырой адамантит (Raw Adamantite), который используется для дальнейшей переработки.
-
_2. ⛏️ПЕРЕРАБОТКА И КУЗНЕЧНОЕ ДЕЛО_
-
Полученный сырой адамантит необходимо переплавить в обычной печи, чтобы получить адамантитовый слиток (Adamantite Ingot).
Из слитков создаются различные предметы с помощью стандартного верстака. Для изготовления экипировки используются привычные рецепты крафта, адаптированные под новый материал.
Таким образом, игроку необходимо сначала обнаружить месторождение, добыть руду, переработать её и только после этого приступить к созданию нового снаряжения.
-
_3. 🪖ЭКИПИРОВКА И ХАРАКТЕРИСТИКИ_
-
Мод добавляет полноценный комплект адамантитового снаряжения, включающий инструменты, оружие и броню.
ИНСТРУМЕНТЫ
В моде представлены:
-
● Адамантитовая кирка.
-
● Адамантитовый топор.
-
● Адамантитовая лопата.
-
● Адамантитовая мотыга.
-
● Адамантитовые ножницы.
-
Инструменты обладают повышенной прочностью и скоростью добычи блоков по сравнению с алмазными аналогами.
-
ОРУЖИЕ
-
Основным оружием является адамантитовый меч, отличающийся повышенным уроном и прочностью. Он предназначен для игроков, которые хотят получить преимущество в сражениях на поздних этапах игры.
-
БРОНЯ
-
Добавляется полный комплект адамантитовой брони:
-
● Шлем.
-
● Нагрудник.
-
● Поножи.
-
● Ботинки.
-
Броня обеспечивает повышенную защиту по сравнению с алмазным комплектом. При использовании полного комплекта игрок получает дополнительные пассивные эффекты:
Снижение урона от падения.
Повышенное сопротивление отбрасыванию (Knockback Resistance).
-
_4. 📋ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ И СОВМЕСТИМОСТЬ_
-
Версия Minecraft: 1.12.2
Загрузчик модов: Minecraft Forge
Зависимости: Отсутствуют
Тип мода: Контентный мод
Основное направление: Новые ресурсы, инструменты, оружие и броня.
-
_5. ⬇️УСТАНОВКА_
-
1. Установите Minecraft Forge для версии 1.12.2.
-
2. Скачайте файл Adamantite Expansion (.jar).
-
3. Откройте папку .minecraft.
-
4. Переместите файл мода в папку mods.
-
5. Запустите Minecraft с установленным профилем Forge.
